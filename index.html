Launch Pad

A simple site for learning hosting, GitHub, and live updates.

Auto deploy ready

Learning hosting the simple way

Build once, push changes, watch the live site update.

This project is small on purpose. You change the files, push them to GitHub, and the hosting platform updates your live website automatically.

See the workflow See the project

What you are learning

  • How a site moves from your editor to the web.
  • How GitHub stores and tracks your changes.
  • How Netlify or Vercel rebuilds the site after push.
Stack HTML + CSS + JS
Hosting Netlify / Vercel
Project type

Static website

Pure HTML, CSS, and a little JavaScript. Perfect for learning the upload and deploy flow.

Best for beginners

Fast to edit

Change one line in index.html or styles.css, then redeploy.

Hosting choice

Auto updates

After you connect GitHub, every push becomes a new deployment on your hosting platform.

Why this project works

It teaches the exact workflow you will repeat later.

The goal is not to build a large app yet. The goal is to understand deployment, live updates, and where your files go when a website is hosted online.
