# Launch Pad

A tiny static website made for learning how hosting works on Netlify or Vercel.

## What this project teaches

- How a website is built from HTML, CSS, and JavaScript.
- How to publish a project from GitHub.
- How to update the live site after changing code.

## Local use

Open `index.html` in your browser, or serve the folder with any local server.

## Deploy on Netlify

1. Put this folder in a GitHub repository.
2. Sign in to Netlify.
3. Choose **Add new site** and connect GitHub.
4. Select the repository.
5. Leave the build command empty.
6. Set the publish directory to the project root.
7. Deploy.
8. After that, edit a file, commit, push, and Netlify updates the live site automatically.

## Deploy on Vercel

1. Put this folder in a GitHub repository.
2. Sign in to Vercel.
3. Import the repository.
4. Keep the framework as static or other.
5. Set the output to the project root if asked.
6. Deploy.
7. After that, every push to GitHub triggers a new deployment.

## How to change the website

- Change the text in `index.html`.
- Change colors and layout in `styles.css`.
- Change the button message behavior in `script.js`.
