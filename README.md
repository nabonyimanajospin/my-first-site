# Launch Pad

A clean starter website for learning the full hosting workflow with GitHub, Netlify, or Vercel.

This project is intentionally small so you can focus on the important part first: how code becomes a live website, how updates are pushed, and how deployments refresh automatically.

## Why this project exists

- Learn the simplest website stack: HTML, CSS, and a little JavaScript.
- Understand how GitHub stores your code online.
- See how Netlify and Vercel publish a site directly from a repository.
- Practice making changes and watching the live site update.

## What is inside

- `index.html` for structure and content.
- `styles.css` for layout, colors, and responsive design.
- `script.js` for a small interactive feature.

## How to run it locally

You can open `index.html` directly in your browser.

If you want a local server, use any simple option such as VS Code Live Server or a basic static server.

## How to update the website

1. Edit a file locally.
2. Save your changes.
3. Commit the change to Git.
4. Push the commit to GitHub.
5. Wait for Netlify or Vercel to rebuild the live site.

That repeatable loop is the main lesson of this project.

## Deploy with Netlify

1. Put this folder in a GitHub repository.
2. Sign in to Netlify.
3. Choose **Add new site** and connect GitHub.
4. Select this repository.
5. Leave the build command empty.
6. Set the publish directory to the project root.
7. Deploy the site.
8. Make a change, push again, and Netlify updates the live version.

## Deploy with Vercel

1. Put this folder in a GitHub repository.
2. Sign in to Vercel.
3. Import the repository.
4. Choose the static site option if Vercel asks.
5. Keep the output at the project root if prompted.
6. Deploy the site.
7. Push a new commit whenever you want the live site to update.

## What to edit first

- Change the headline in `index.html`.
- Change the colors in `styles.css`.
- Change the button messages in `script.js`.

## Suggested learning order

1. Read the HTML and understand the page structure.
2. Change the text and refresh the page.
3. Change the colors and spacing.
4. Push the project to GitHub.
5. Deploy it on Netlify or Vercel.
6. Make one more change after deployment so you can see the update cycle.
